开始之前：这份教程适合你吗？

先说清楚这个程序是干什么的，以及它的边界。

✅ 适合你，如果你
  • 玩《明日方舟》《原神》《崩坏：星穹铁道》中的至少一个
  • 已经用过或愿意用 MAA / BetterGI / 三月七小助手这类自动化工具
  • 想「人不在电脑前，也能让电脑把日常跑完」
❌ 不适合你，如果你
  • 你期待本程序替你操作游戏 —— 不，它只是遥控器， 真正干活的是 MAA / BetterGI / 三月七
  • 你完全没接触过自动化工具 —— 能装，但建议先把 MAA 单独用熟再回来
  • 只是偶尔上线看看游戏 —— 装一堆工具不值得
⚠️ 必须知道
  • 本程序不修改游戏、不读游戏内存，只是把点击转给第三方工具
  • 封号风险没有任何官方承诺。用不用请自己判断
  • 本程序是胶水，能力上限 = 你装的三个工具的能力上限
  • 所有数据（配对凭据、日志、配置）只存在你自己电脑上

第一步：装三个自动化工具

这一步和本程序没有任何关系，全是第三方开源工具。 建议每个工具先单独跑通一次，确认它能正常操作游戏，再回来看本程序。

你玩需要装大概耗时
只玩明日方舟MAA + MuMu 模拟器 + 游戏本体20 分钟
只玩原神BetterGI + 游戏本体10 分钟
只玩星铁三月七小助手 + 游戏本体10 分钟
都玩上面全部40 分钟
明日方舟 → MAA + MuMu
  1. 打开 mumu.163.com/download 装 MuMu 模拟器
  2. 在模拟器里装《明日方舟》并登录
  3. 打开 maa.plus 下载 Windows x64 版
  4. 解压到简单路径，比如 D:\MAA。 别放 C:\Program Files（需要管理员权限会出错）
  5. 先运行目录里的 DependencySetup_依赖库安装.bat，再双击 MAA.exe
  6. 在 MAA 里添加账号、连接 MuMu
  7. 手动点一次「开始唤醒」和日常，确认能正常工作
🔑 关键一步：MAA 设置里要打开远程控制 （设置 → 远程控制 → 记住端口，默认 8080）。本程序靠它给 MAA 下发任务。
原神 → BetterGI
  1. 打开 bettergi.com 下载
  2. 解压运行，首次启动会让你选《原神》的游戏目录
  3. 在 BetterGI 里手动跑一次「一条龙」，确认能正常工作
星穹铁道 → 三月七小助手
  1. 打开 m7a.top 下载
  2. 解压运行，让它自动识别游戏的安装位置
  3. 手动跑一次日常，确认能正常工作
游戏本体还没装？
  • 《原神》 ys.mihoyo.com
  • 《崩坏：星穹铁道》 sr.mihoyo.com
  • 《明日方舟》在 MuMu 模拟器里装
装完之后，本程序会自动找到它们。找不到的话，本程序「依赖清单」页可以手动指定路径。

第二步：拿到你的固定地址

这一步是为了让你出门在外时，手机也能连回家里的电脑。 Tailscale 只装在电脑上，手机端不用装。

这个地址是怎么来的？
它不是凭空有的，是你做完下面四步之后，Tailscale 给你的：
步骤做完之后
① 注册 Tailscale 账号有账号了，还没有地址
② 电脑安装 Tailscale装了，还没有地址
③ 点 Log in 登录有内网地址，手机还连不上
④ 开启 Funnel🎉 公网固定地址出现了
  1. 注册：打开 login.tailscale.com/start， 用 Google / GitHub / 微软账号登录（免费档够用）
  2. 装到电脑上：从 tailscale.com/download/windows 下载安装。装完右下角托盘区会有图标（可能要点开 ^ 箭头）
  3. 登录：点托盘图标 →「Log in」→ 浏览器里点授权
  4. 开启 Funnel：用管理员身份打开 PowerShell，执行： 
    tailscale funnel --bg 8765
    第一次会弹浏览器让你点一次授权。完成后会输出类似： 
    Available on the internet:
https://你的主机名.你的随机串.ts.net
|-- / proxy http://127.0.0.1:8765
关于那串随机字符
地址由三段组成：https://主机名.随机串.ts.net
  • 主机名 = 你电脑的名字
  • 随机串 = Tailscale 注册时随机分配的，每个人都不一样
  • ts.net = 固定后缀
所以不能照抄别人的地址，必须用你自己电脑上显示的那个。 记不住也没关系——本程序会自动读到并显示出来。
这一步只需要做一次。以后开机、重启程序，地址都不会变。

第三步：装本程序（电脑端）

解压即用，不需要安装。

  1. 从本项目 Releases 下载 阿福代肝控制器.zip，解压到任意位置（别放 Program Files）
  2. 双击 阿福代肝控制器.exe
  3. 弹 UAC 权限请求 → 点「是」（必须，否则无法模拟键鼠）

打开后你会看到：

总览页

区域看什么
服务绿点「服务运行中」= 正常；「✓ 运行所需的软件都装好了」= 第一步装的东西它都找到了
① 填地址那个 https://xxx.ts.net 就是要填到手机里的，旁边有「复制地址」
② 填配对码手机配对时输入的 6 位数字
游戏状态三个游戏各显示「可用」或「缺什么」
如果显示「⚠ 还缺 XXX」，去左侧「依赖清单」页看是哪一项没装好，那里有官网下载链接。

第四步：装 APP 并连上电脑

4-A 安装 APP

从本项目 Releases 下载 阿福代肝控制器.apk 装到手机上（允许「未知来源应用」）。

4-B 填地址和配对码

手机 APP 的连接页

填什么从哪来
电脑地址电脑端「总览」页的 https://xxx.ts.net，点「复制地址」
配对码电脑端「总览」页的「② 填配对码」

填完地址点「连接」，连上后填配对码点「配对」。成功会显示 ● 已连上电脑 · 服务版本 x.x.x。

在同一个 WiFi 下？ 手机和电脑连同一个路由器时，可以直接点「搜索同一网络里的电脑」， 不用手抄地址。出门在外才需要填那个 https:// 地址。
电脑端显示「还拿不到地址」？ 说明第二步第 4 小步（开启 Funnel）没做完。 电脑端「连接」页有四步检查表，哪一步红就去做哪一步。

第五步：用起来

连上之后的主界面

  • 底部三个图标：切换 明日方舟 / 原神 / 星穹铁道
  • 画面：电脑屏幕的实时截图，任务在跑时自动刷新
  • 「开始XXX」按钮：固定在底部，点一下启动对应的一条龙
  • 「关闭并释放内存」：任务结束后关掉游戏和工具
想做什么怎么做
跑原神一条龙底部点「原神」→「开始一条龙」
看任务跑到哪了看画面区，或看下方任务卡片的日志
中途停下底部「停止任务」
换一台电脑「连接设置」→ 填新地址 → 重新配对
释放内存「关闭并释放内存」
任务正常结束（成功/失败/超时）会自动关掉游戏和工具释放内存； 如果你是手动点停止的不会自动清理（可能你还要接着玩），需要时点「关闭并释放内存」。
🎉 到这里就全部完成了。
以后开机只需要：双击阿福代肝控制器 → 手机打开 APP 就能用（地址和配对都记住了）。
