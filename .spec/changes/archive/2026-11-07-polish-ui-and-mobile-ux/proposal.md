# 变更：界面重做（桌面 + 手机）

## 动机

功能已经能跑，但界面停在「能用就行」的状态。用户的原话：

> 电脑 exe 程序界面难看图标丑陋，打开网页我也没点开成功过
> 手机 UI 一样的图标丑陋界面不合理，互动不合理

具体问题：

- **手机没有应用图标**：`AndroidManifest` 里写的是 `@android:drawable/sym_def_app_icon`，就是安卓默认的绿色小机器人
- **底栏三个游戏共用一个图标**：三个都是 `Icons.Default.PlayArrow`，根本分不出谁是谁
- **连接设置页退不出去**：整页替换式实现，没接系统返回，左右滑一下 APP 直接退了
- **电脑端是 tkinter 朴素表单**：vista 主题 + 灰底 LabelFrame，没有品牌感，exe 也是默认图标
- **游戏页信息层级乱**：画面在最上面、按钮在很下面，要滚很久才够得着

## 范围

在范围内：

- 手机端：原创应用图标（自适应图标，适配各厂家形状）、三个游戏的区分图标、连接页返回手势与返回键
- 手机端：游戏页信息层级调整，主操作按钮始终可见
- 手机端：触摸区域不小于 48dp、可点击元素有按压反馈、不可用按钮说明原因
- 电脑端：改用 PySide6/Qt 重做界面，侧边栏 + 卡片 + 深浅主题
- 电脑端：应用图标（窗口、任务栏、exe）
- 电脑端：耗时操作不冻结界面
- 两端共用一套设计语言（配色、圆角、状态色）

不在范围内：

- 新增业务功能（接口、引擎、任务调度都不动）
- 手机端的整体导航结构大改（仍是三个游戏 + 连接设置）
- 桌面端换技术栈以外的重构（服务层保持 Python）
- 多语言、无障碍朗读

## 方法

**图标全部原创绘制**：用矢量路径画风格化的几何图形（方舟 / 风之翼 / 星轨），
只取游戏的气质，不使用任何厂商美术素材或商标——这是开源分发的前提。

**手机端**保留 Compose，把图标做成 `ImageVector` 或矢量 drawable，
底栏改为「图标 + 短标签 + 选中态胶囊」，连接页改为受返回事件管理的二级页面。

**电脑端**用 PySide6 重写 `desktop/main.py` 的视图层，服务启动、探测、隧道这些
已有的类（`ServiceHost` / `TunnelHost`）尽量原样复用，只换掉 tkinter 那层。

**设计语言**两端统一：同一套主色与状态色，圆角半径一致，深色为默认。
