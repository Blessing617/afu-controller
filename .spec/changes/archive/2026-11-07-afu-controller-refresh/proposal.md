# 变更：阿福代肝控制器（改品牌 + 性能 + 通用连接设置）

## 动机

1. **品牌**：应用现在叫「游戏编排器」，图标是一个抽象的播放三角 + 十字键，不像一个「人」做的产品。
   要改名为「阿福代肝控制器」，换成有辨识度的大肥鱼形象（抱着手柄）。
2. **卡**：手机 APP 和电脑端都明显掉帧，最耗的两处已经定位：
   电脑端每 2 秒在界面线程上同步拉起 `tailscale` 子进程 + 刷新地址；手机端每次状态轮询都
   重建一次数据类并重组整棵界面树，截图每 20 秒拉一张全屏 JPEG。
3. **编排**：连接设置是通用能力，现在却塞在每个游戏页里（手机端每个游戏页底部都有一条
   「连接设置」按钮），桌面端也把它和总览页的地址信息重复了一遍。
4. **体验细节**：
   - 明日方舟的截图走 ADB（要拉起 adb 子进程、在模拟器里 `screencap`），既慢又和另外两个
     游戏不是一套东西——既然画面本来就是全屏截图，三方舟也统一成全屏截图。
   - 手机端从方舟切到原神会整页「刷新一下」再显示，因为画面、任务卡、按钮全都跟着游戏 key
     重建了；实际上三个游戏共用同一张全屏截图，没必要。
   - 只有一两款游戏装好时，界面也要能正常用，不能因为缺某个游戏就空白或报错。
5. **动画**：界面切换是硬切，想要参考阿福记账那种「有方向、有纵深、有落位感」的过渡。

## 范围

在范围内：

- 显示名统一为「阿福代肝控制器」：exe 名、窗口标题、侧边栏品牌、安卓 `app_name`、
  网页控制台与引导页里的产品名；安卓包名 `com.gameorch.app` → `com.afu.controller`。
- 应用图标：原创矢量「大肥鱼抱手柄」，同时产出 exe 的 `.ico`、窗口/侧边栏图标、
  安卓自适应图标（前景/背景/单色三层）。
- 性能：电脑端把 `tailscale` 调用、地址枚举挪出界面线程并按需刷新；
  手机端状态轮询只在数据真的变了时才发射新状态，减少无谓重组；截图解码下沉到 IO 线程。
- 截图：`/api/screen/{game}` 三个游戏一律返回全屏截图，不再为方舟走 ADB。
- 手机端编排：连接设置从每个游戏页移到独立的设置入口（全局唯一入口）。
- 手机端切页：游戏页切换只换内容，不重建画面区与主操作栏。
- 兼容性：只有一款或两款游戏可用时，底栏、游戏页、设置页都正常可用。
- 过渡动效：统一一套动效 token（方向位移 + 纵深缩放 + 弹簧/减速曲线）。

不在范围内：

- 不改服务端接口的路径与返回结构（除了方舟截图内部实现的替换）。
- 不改数据目录位置、不改配对凭据格式（但包名变了，手机端需要重装一次）。
- 不做大改版：不引入新的导航层级、不做主题换肤、不做背景图。
- 不把 exe 改成 Electron 或换技术栈，继续用 PySide6 + PyInstaller。
- 不追求把「分钟级冷启动」变成「秒开」的重构；只治可测量的卡顿点。
