# 变更：五个实机问题修复

## 动机

在真实使用中暴露出 5 个问题，都不是「功能没做」，而是「在真机上跑起来才暴露」的缺陷：

1. **连接时序**：先开手机 APP、后启动电脑端时，APP 永远停在读取中，必须重开 APP
2. **清理不彻底**：方舟清理只关了 MuMu 虚拟机，主程序 `MuMuNxMain` 仍然常驻
3. **MAA 启动弹窗**：`RemoteControlUserIdentity` 加解密失败
4. **BGI 遮罩窗口**：原神启动时 BGI 会在游戏上盖一个半透明遮罩窗口
5. **焦点竞争**：星铁任务报「无法切换到指定游戏界面」，多个工具窗口互相抢焦点

## 范围

在范围内：
- APP 连接状态机：自动重试、手动重连/断开
- 清理逻辑覆盖 MuMu 主程序
- MAA 远程控制配置的兼容处理
- BGI 遮罩窗口关闭
- 任务运行期间的窗口焦点管理

不在范围内：
- 新增游戏或引擎
- 异常自愈的其它条目（仍在 docs/05）

## 方法

逐项按「实测复现 → 定位根因 → 修 → 复测」推进，每项都在真机上跑过一遍再收。
