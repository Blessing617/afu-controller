# 变更：新手引导补强（地址从哪来、缺什么软件）

## 动机

用户实测时问了一句：「我现在都不知道电脑地址从哪来」。

以新人视角走了一遍，确实是断的：

1. **总览页只有一串数字，没有「拿去干什么」的说明**
   旧界面显示 `配对码 146915` 和 `100.x.x.x:8765 192.168.x.x:8765 ...`，
   但没有任何一句话说明「这个地址要填到手机 APP 里」。
2. **推荐填哪个地址也不说**
   列出四个地址，新人不知道该选哪个。而真正该用的那个（Funnel 固定域名）
   还藏在「连接」页里。
3. **缺软件时总览页不提示**
   新人不点进「依赖清单」就不知道还要装 MAA / MuMu / BetterGI。
4. **「已在运行」的弹框没有可操作信息**
   原文案是「请查看任务栏」，但任务栏可能堆了二十个图标。
5. **`tailxxxxxx` 这串从哪来没解释**
   README 里只写「会输出你的固定域名」，没说这串是 Tailscale 随机分配的、
   每人不同、不能照抄文档里的示例。

## 范围

在范围内：

- 总览页「手机怎么连上这台电脑」卡片：分步骤、大字显示推荐地址、一键复制
- 推荐地址的选取逻辑：Funnel 固定域名 > 局域网地址
- 总览页同步显示依赖是否齐全
- 「已在运行」弹框给出可操作的排查步骤
- README 补「网址每一段是什么意思」与「为什么不能照抄」

不在范围内：

- 手机端改动（上一轮已做）
- 服务端接口改动
- 完整的首次启动向导（本次只强化总览页）

## 方法

总览页把「连接信息」从「一堆数字」改成「照着做的两步」：
① 填地址 → ② 填配对码。地址用大号等宽字体 + 复制按钮，
避免用户手抄长字符串出错。

推荐地址的选取规则写清楚：**有 Funnel 就用 Funnel**（出门在家都能用、手机不用装东西），
没有才退回局域网地址，并说明局限。
