# 变更：新手图文引导

## 动机

用户列出这个项目本该做到的五件事：

1. 用户须知 —— 建议用过三个工具的人使用，给出 MAA 等的说明与前置条件
2. 引导用户下载 MAA、MuMu、原神、BetterGI
3. 连接引导 —— 下载 Tailscale、注册、拿到固定地址
4. 本软件的教学
5. APP 的使用

实际情况是：

- 引导页只有三步（许可 / 依赖 / 连接），约 8KB，**没有任何截图**
- README 516 行纯文字，没有图
- **完全没有 APP 的使用说明**
- 没有「这份教程适不适合你」的前置说明

用户的核心诉求是**图文引导**，落在 README（GitHub）与程序内引导页两处。

## 范围

在范围内：

- 新建 `docs/新手图文教程.md`：0–5 六步完整图文教程
- 重写程序内引导页 `welcome.html`：同样的六步，带截图
- 补充真实界面截图（本程序自己的界面）
- README 顶部加入教程入口与「地址从哪来」速览

不在范围内：

- 第三方工具（MAA / BetterGI / 三月七 / Tailscale）自身的界面截图
  —— 那些是本程序之外的东西，教程只需要告诉用户去哪下载、装完接什么，
  不需要也不应该放它们的界面图
- 手机端代码改动

## 方法

内容按「用户实际会问的问题」组织，而不是按功能模块：

- 第 0 步先劝退：说清楚这程序不做什么（不替你操作游戏、封号风险自担）
- 第 1 步是纯第三方工具安装，明确写「和本程序没关系，先单独跑通」
- 第 2 步用表格把「做完哪一步之后有什么、没有什么」讲透，
  回答「地址从哪来」这个被反复追问的问题
- 第 3、4 步配本程序自己的界面截图
- 第 5 步讲日常使用

截图只用本程序自己的界面，因为只有这些是真实、准确、且属于本项目的。
