# 变更：修复命令文字不可见与返回键失效

## 动机

用户实测发现两处硬伤：

### 1. 桌面端命令框黑底黑字

「连接」页的四步指引里，`tailscale funnel --bg 8765` 那条命令显示成一片深色，
**文字完全看不见**。

原因：`QLabel.setStyleSheet()` 只设了 `background` 没设 `color`，
文字颜色沿用默认黑色，压在深色背景上就看不见了。

### 2. 手机 APP 返回键退不出连接页

用户反馈：「无法退出到一级界面，左右滑就是返回手机桌面了」。

原因：`BackHandler(enabled = showConnect && state.paired)` 这个条件，
在**未配对的新用户**身上恒为 false，于是返回键完全不拦截，APP 直接被退回桌面。

而用户当时正好处在清空数据后的首次使用状态 —— 也就是这个 bug 必定触发的场景。

## 范围

在范围内：

- 修复命令框的文字颜色
- 修复手机端返回键在未配对状态下的行为
- 检查其它「只设背景不设文字色」的地方

不在范围内：

- 其它界面改动

## 方法

1. 命令框同时设 `background` 与 `color`，用当前主题的文字色。
2. 返回键改成显式的三分支：能回主界面就回；不能回给提示但不退出；
   已配对且在主界面时放行让系统正常退出 APP。
3. 把 `AppViewModel.toast()` 从 private 改为 public，供界面层提示用。
