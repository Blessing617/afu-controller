# 变更：双端界面重做（深海奶油糖果）

## 动机

用户原话：「当前桌面应用界面 UI 设计不好看，元素布置不够合理，包括内容显示好看；
手机 APP 也是一样的，重点点名添加定时任务的地方，一看就是用了现成组件，风格都不统一的。」

现状的具体问题（不是审美偏好，是能指着截图说的）：

**电脑端总览页**

1. 侧边栏品牌区、导航项挤在顶部，下方留出整块空白，视觉上「没做完」；
   选中态是一整块饱和蓝实心矩形，和卡片区的圆角语言不是一套。
2. 连接卡里「② 填配对码」下面直接一个巨大字号的「已配对」，把**状态**当成了**标题**，
   层级错乱；配对码区域没有可执行的东西（没有「重新配对」以外的信息）。
3. 「其它可用地址」一行摘要 + 下面四行地址列表**同一组信息显示了两遍**，其中一行还因为
   宽度不够被折断。
4. 服务卡内标题、绿点、状态文字、按钮四者的基线和对齐都不齐，卡片内大片空白；
   卡片之间间距不均，最后一张卡被窗口底部裁切。
5. 字号靠各处 `setPixelSize` 硬编码，同一层级文字在不同页面大小不一；
   字体是系统微软雅黑，没有任何品牌感。

**手机端**

6. 编排页「定时执行」卡片：时间选择用的是 Material3 原生 `TimePicker`（时钟盘），
   星期/时间点用 `AssistChip`、`FilterChip`，删除确认用原生 `AlertDialog`——
   与本项目自己那套卡片、状态色、动效完全不是一套语言，一眼就是「拼进来的组件」。
7. 相同问题散落在任务选择弹层、步骤卡、设置页的对话框上。

**两端共同**

8. 没有一套两端共用的设计系统：配色 token 有了（`tokens.py` / `Theme.kt`），
   但形状、按钮质感、字体、图标、动效曲线各写各的。

## 范围

在范围内：

- 新增 `design-system` 能力：两端共用的视觉 token（配色 / 圆角 / 间距 / 字阶 / 动效曲线）、
  组件质感（胶囊按钮、果冻按压、卡片层次）、可执行的一致性检查。
- 电脑端：侧边栏、总览页、依赖清单、设置页、首次引导页的布局与视觉重做。
- 手机端：主界面（顶部状态 / 画面 / 任务卡 / 主操作 / 底栏）、编排页与定时编辑、
  任务选择弹层、设置页、连接页的视觉统一；把原生 `TimePicker`、`FilterChip`、
   原生对话框替换为自绘的糖果组件。
- 视觉方向：**深海奶油糖果**——奶油暖白底 + 鲸鱼蓝主色 + 珊瑚强调色 + 大圆角胶囊 +
  果冻按压回弹；浅色为默认，深色为「深夜海沟」变体，跟随系统。
- 字体：打包一款开源中文字体（OFL）用于标题、数字与时间，正文回退系统字体；附授权文件。
- 美术资源：新增原创矢量装饰（尾鳍、气泡、水波、果冻高光），并记录来源与授权。
- 动效：按钮按压、页面切换、卡片进场、开关与选中态的过渡，统一曲线与时长；
  系统关闭动画时退化。
- 流畅度：两端在既有 `performance` 预算内完成上述改动，手机端用 **release 包**在真机验证。

不在范围内：

- **任何功能变更**。接口、协议、任务生命周期、定时触发逻辑、配对逻辑一行不改。
- 服务端 API 与网页控制台（浏览器里那个页面）——第三端不在本次「双端」范围内，
  只要求不被这次改动搞坏。
- 图表化 / 新数据展示（如历史任务趋势）——没有需求来源。
- 开屏动画、启动音效、进度条动画等会增加启动耗时的装饰。
- GitHub 发布、README、脱敏——那是另一个变更 `publish-open-source`。

## 方法

先落一份两端共用的设计系统（token + 组件规范 + 动效曲线），再按「电脑端 → 手机端」顺序
逐页重做，每一页都以「改前 / 改后截图对比 + 功能冒烟」为完成标准。
电脑端沿用 PySide6 + QSS，需要「果冻感」的地方用自绘 `QPushButton` 子类做按压缩放，
不引入阴影特效（`QGraphicsDropShadowEffect` 在滚动列表里代价高）。
手机端沿用 Compose，自绘时间选择器与选择胶囊，不用 Material3 的现成弹窗组件。
字体与图标全部走本地资源，不联网加载。
