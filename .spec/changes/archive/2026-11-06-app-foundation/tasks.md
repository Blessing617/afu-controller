# 任务

## 1. 电脑端服务基座

- [x] 1.1 建立 `server/` 项目结构（`app/`、`app/api`、`app/engine`、`app/discovery`），创建项目内虚拟环境 `.venv` 并安装 FastAPI + Uvicorn — 验证：`server\.venv\Scripts\python.exe -c "import fastapi,uvicorn"` 无报错，且 `pip show fastapi` 的 Location 指向项目内
- [x] 1.2 实现配置加载（端口、数据目录、手动路径覆盖），配置文件放项目内 `server/data/config.json` — 验证：改端口后重启服务，`/api/health` 在新端口响应
- [x] 1.3 实现 `GET /api/health`（无需鉴权，返回版本、是否待配对、时间戳）— 验证：`curl` 返回 200 与 JSON

- [x] 1.5 实现 `GET /api/status`（服务版本、三引擎可用性、锁屏状态、权限状态、当前任务）— 验证：返回 JSON 字段齐全，锁屏时 `locked=true`
